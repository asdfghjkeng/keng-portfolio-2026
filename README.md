# Jesseca C. Gimo – Portfolio

Static site: `index.html`, `styles.css`, `script.js`, `assets/photo.jpg`.

## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension.
3. Right-click `index.html` > "Open with Live Server".

Fonts load from Google Fonts, so you need internet the first time.

## Edit
- Text: `index.html`
- Colors and fonts: variables at the top of `styles.css`
- Photo: replace `assets/photo.jpg`
